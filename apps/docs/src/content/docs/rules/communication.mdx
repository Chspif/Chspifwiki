⚠ 基本的素质是本服的底线，请仔细阅读本页面。


- 请保持基本的素质和良好的态度，友好与其他玩家交流，保持对其他玩家的尊重。在提出问题前，请确保你的问题实属个人无法解决，不要浪费大家的时间和精力。如果你愿意，欢迎你花一点时间阅读["提问的智慧"](https://github.com/ryanhanwu/How-To-Ask-Questions-The-Smart-Way/blob/main/README-zh_CN.md)
- 禁止在任何公共交流频道刷屏，禁止转发违法违规、有悖道德、恶趣味、烂梗等令人反感的内容。交流方式请合理，不要充满戾气。
