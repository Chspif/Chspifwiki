---
title: 注意事项
description: 共享服务器注意事项
---

- 重要数据请自行备份，服务器不对数据丢失负责
- 合理使用服务器资源，避免影响其他用户
- 发现异常或违规行为请及时反馈
- 以下行为在服务器上被严格禁止：

    搭建各类网站、Web服务

    任何形式的加密货币挖矿

    搭建钓鱼网站或进行钓鱼攻击

    进行金融交易、洗钱等违法活动

    搭建或使用代理翻墙服务

    对服务器或外部网络进行端口扫描

    使用服务器作为代理发送网络请求

    长时间占用服务器资源，影响他人使用

    传播违法、色情、暴力等不良信息

    攻击、入侵他人账户或服务器系统

    利用服务器进行网络攻击
    
    存储或传播恶意软件、病毒、木马等

    滥用服务器资源进行爬虫、刷量等行为

    任何违反国家法律法规的行为
