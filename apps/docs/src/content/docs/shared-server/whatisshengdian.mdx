本服务器在宣传等面向公众的方面，一直以生电服自我定义，为避免争议，故给出以下解释。

“生电”是一个结合了多个概念的术语，它主要指的是在生存模式下，玩家通过运用红石电路及其他游戏机制，构建出能够实现资源自动化生产、收集或处理等功能的系统。这些系统不仅提高了玩家在生存模式下的效率，还极大地丰富了游戏体验，展现了玩家的智慧和创造力。

我们认为，生电的核心在于其对于红石、游戏特性、甚至代码层面的研究，通过玩家的智慧和创造力设计资源自动化系统，所以在不违反我们所理解的生电精神下，结合游戏便利、游戏乐趣等一系列考虑，会引入非原版修改。

服务器会有一些异于原版的内容，但也有相应的修改底线，我们认为如下修改行为是合理的：

1.生电玩法公认的修改内容，例如：
- Carpet的仙人掌扳手
- Carpet的绊线复制修复

2.合理的辅助内容，例如：
- 小地图、投影等辅助类模组
- 快捷潜影盒模组

3.合理的机制修改，例如：
- Carpet实现雷击坚守者产生海绵

4.不影响游戏机制的娱乐内容，例如：
- 娱乐性质的游戏成就
- 幻翼可以驯化骑乘

当然如下行为我们认为是不合理的：

1.过度影响游戏原本机制，例如：
- 击杀僵尸掉落钻石

2.过分脱离原版范畴，例如：
- 机械动力模组
