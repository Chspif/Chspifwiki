在不过于影响原版机制的情况下，我们修改了一些与原版不符的内容：   

- 对于各类工作台、潜影盒、末影箱等，你可以直接拿在手中右键打开
- 不死图腾在背包里就会自动生效，哪怕它在潜影盒里
- 拴绳不会被高速移动别断
- 末影人不会拿起方块
- 末影龙不会破坏方块；当末影龙复活时，祭坛和黑曜石柱不会再生成
- 仙人掌扳手
- 音符盒加载（骨块）
- 经验修补可以自动修复背包内物品
- 重新引入绊线欺骗
- 掉落物/矿车发光
- 下界合金稿可以加速玻璃、玻璃板、发光透明方块、蛙鸣灯的挖掘
- 玩家可以获取头颅
- 可以强制打开被阻挡的容器
- 当末影龙被闪电苦力怕杀死时掉落龙首
- 你可以合成鞘翅
