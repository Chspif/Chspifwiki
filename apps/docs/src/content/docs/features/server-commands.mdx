## 常用指令  

`/getPlayerSkull <玩家> <数量>`  
　　　获取某个玩家的头颅   

`/seed`  
　　　获取服务器种子  

`/killMe`  
　　　自杀   

`/xpTransfer <输出玩家> <输入玩家> <单位> <数量>`    
　　　转移玩家经验（仅限假人与自己）   
    
`/trigger smallfix`   
　　　进入/退出检修模式（缩小玩家体积）  

`/player`等carpet指令   
　　　自行查阅carpet指令文档   

`!s` 或 `!!spec`   
　　　高级版灵魂出窍（切旁观，切回生存传送回原位置）   

`!d`或`!!st`   
　　　根据当前坐标在地狱和主世界间快速切换，自身必须是非生存模式且处于地狱与主世界间的任一维度   

`!!st id <玩家>`   
　　　传送到某个玩家，自身必须是非生存模式    

`!!st <x> <y> <z>`   
　　　传送到自身所在维度的指定坐标,自身必须是非生存模式   
    
`!!st <x> <y> <z> in <维度:0主世界,-1地狱,1末地>`   
　　　传送到某个维度的指定坐标,自身必须是非生存模式   

`!!wp list [<page>]`   
　　　列出所有的公共坐标点，page不填则默认为1

`/getsavesize`   
　　　获取服务器存档的大小   

`!!pb make <注释>`   
　　　进行一次主动备份   

`/kick <玩家> [<原因>]`  
　　　踢出某个玩家
