这里列举了作为普通玩家，你可以使用的一些指令

- 使用"  /getPlayerSkull 名字 数量   "获取某个玩家的头颅
- 使用"    /getsavesize    "获取服务器存档的大小
- 使用"    /kick   "踢出某个玩家
- 使用"    /seed    "获取服务器种子
- 使用"    /killMe    "自杀
- 使用"    /xpTransfer   "转移假人经验
- 使用"    /trigger smallfix   "进入检修模式
- 使用"    !s   "进入旁观者模式，再次使用会返回生存模式
- 使用"    !!st id 名字    "在旁观模式下传送到某个玩家身边
- 正常的一些carpet指令
